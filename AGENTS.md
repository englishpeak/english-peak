# English Peak agent instructions

Before making visual/UI changes, read `docs/BRANDING_AND_DESIGN.md` and use `styles/brand-tokens.css` when practical.

Core design rules:
- Use Outfit for interface/body text and Cormorant Garamond for titles/brand moments.
- Keep the primary palette anchored in navy `#0D3B6F` and purple `#470074`.
- Prefer light app backgrounds, white cards, subtle navy borders, rounded corners, and soft blue-tinted shadows.
- Do not introduce a new visual language unless the user explicitly asks for it.
